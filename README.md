# sql-database-practice

A collection of small SQL exercises and scripts from a database course, kept together since none is substantial enough to stand alone.

- `HRSchema` — HR schema scripts (DEPT/EMP/SALGRADE tables) built up across several weeks
- `OrdersProductsTables` — creates and populates Orders, Order_Line, and Products tables
- `CustomersSchema` — creates a Customers table
- `FlightDatabase` — queries against a flight database, with a backup and ER diagram of the schema
- `Diagrams` — a standalone associative-relationships ER diagram
